### Ringkasan Produk
**Realtime Action Gesture Automator (RAGA)** adalah aplikasi penjejakan postur dan pergerakan tubuh real-time yang dapat ditranslasikan menjadi kontrol input mouse dan keyboard pada komputer.

### Implementasi
Aplikasi ini memanfaatkan model machine learning pelacakan landmark tubuh berbasis webcam standar tanpa memerlukan perangkat sensor VR mahal. Telah didemonstrasikan sukses mengendalikan karakter dalam permainan video dan navigasi antarmuka presentasi.
